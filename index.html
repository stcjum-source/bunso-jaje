직원 화면에 게시

여기서 고친 내용(SAP 반영·실사 수량·평면도)은 이 PC 브라우저에만 저장됩니다. 🚀 바로 게시를 누르면 깃허브에 올라가고, 보통 1~10분 뒤 직원 폰에 반영됩니다.
깃허브 연결 설정 (처음 한 번)
설정값은 이 PC 브라우저에만 저장되고, 직원에게 게시되는 파일에는 들어가지 않습니다.
접근키 만드는 법
① github.com 로그인 → 오른쪽 위 프로필 → Settings
② 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
③ 이름 입력, 만료기간 선택(최대 1년 — 만료되면 새로 만들어 넣으면 됨)
④ Repository access: Only select repositories → 이 저장소 하나만 선택
⑤ Permissions → Repository permissions → Contents: Read and write
⑥ Generate token → 나온 키(github_pat_…)를 복사해 위 칸에 붙여넣고 설정 저장 → 연결 확인
이 키로는 이 저장소 하나만 바꿀 수 있습니다. 잘못 게시돼도 깃허브에 이전 기록이 남아 있어 되돌릴 수 있습니다.
파일로 직접 올리기 (깃허브 연결 없이)
① 아래 버튼으로 index.html 저장 → ② 깃허브 저장소에서 Add file → Upload files로 덮어쓰기 → ③ Commit
